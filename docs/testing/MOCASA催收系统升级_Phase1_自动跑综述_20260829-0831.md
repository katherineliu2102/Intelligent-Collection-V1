## 5. 做了哪些修改



### 5.1 8/29 23:12 — 只改 env

- `COLLECTION_PILOT_LOAN_IDS` / `COLLECTION_SCAN_CASE_IDS` 换成 e2e200 的 200 个 ID。
- 重启，未重编 jar。备份 `pilot.env.bak.20260829151248`。



### 5.2 8/30 17:39 — 产品包 + 空名单

在 8/27 `4ca65f5` 底上叠（本机 `test_branch_0828` 缺类型编不过，Pilot 用 `origin/test_branch` 叠补丁）：


| 改动                                                            | 目的                              |
| ------------------------------------------------------------- | ------------------------------- |
| 空 `loan-id-whitelist` 可启动（warn，不拒启）                           | 消费订阅内全部案件                       |
| Pilot 扫描空名单告警放行；`pilot-run.sh` 允许两份名单为空                       | 否则清名单后脚本把空值当缺配，起不来              |
| `daily-roll-full-scan-enabled` 默认 **true**                    | 空名单按 `t_ai_collection` keyset 滚 |
| `cancelPlan` → `skipOpenSteps`（升档/停催/还款/preflight）            | 取消后 PENDING/EXECUTING 收口        |
| 发送前 `refreshVolatileFields` 写当天 `stage`；建计划落 `snapshot.stage` | 话术跟今天档                          |
| 发版前 SQL：非 e2e200 活跃计划 `MANUAL_CLEANUP`，打开步 SKIPPED            | 扫描放开后不捞原 40                     |


回滚：jar `collection-admin.jar.bak.202608301732`；env `pilot.env.bak.20260830093728`（仍是 200 名单）。

加量/换名单：**改数仓 Publisher**，不要再手改这两份 env。

### 5.3 8/31 — 日切续档（已发版，11:58 手动补跑）

`DpdStageRollHandler`：无活跃计划时读最近一份计划。`PLAN_COMPLETED` 且投影档已变 → `STAGE_CHANGED` 建当天档（S0→S1 … S3→S4）。`MANUAL_CLEANUP` / `REPAID` / `CEASED` 不续建。`NO_DUE_BALANCE` 取消后投影已有余额则按当天档重建。不改 AdvancementPolicy。

Pilot：11:53 health 200；删 `collection:ingestion:daily-roll:2026-08-31:completed` 后发 `job=dailyRoll`。`fullScan=true scanned=179 stageChanged=10 ceased=0 rollbackSkipped=0`。

### 5.4 8/31 14:19 — 日期解析 + S0 upcoming

`CasePayloadMapper.parseDate`：认 `yyyy-MM-dd`、`…T00:00:00.000`、空格日期时间、`0`/null；取前 10 位日历日。S0 PreFlight / 日切续建 / Facade 金额认 `upcomingAmount`。已 ACK 的毒丸**不会**因这次发版重投。

回滚 jar：`/opt/app/build/collection-admin.jar.bak.202608310618`（UTC 时间戳 = PHT 14:18）。
