## 1. 测试层级与状态规则

|---|---|

| 标记 | 含义 |
|---|---|
| ✅ | 当前代码与契约版本已执行并满足退出条件 |
| 🟡 | 已部分通过，仍有明确未关闭项 |
| ⬜ | 未执行或未满足准入 |
| ⏭ | Phase 2 或当前范围外 |

测试阶段按 `T0 → T1 → T2 → T3 → T3o → T4 → T5 → T6` 推进。代码、契约或环境发生实质变化后，受影响用例必须重跑。
