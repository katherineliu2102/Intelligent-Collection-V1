## 5. Owner 路由分流怎么用

1. 白名单同时配：  
   - 接入 `COLLECTION_PILOT_LOAN_IDS` / `collection.ingestion.loan-id-whitelist`  
   - 扫描 `COLLECTION_SCAN_CASE_IDS` / `collection.scan.case-id-whitelist`
2. 数仓侧：对分流比例可配置；本清单是 **批准可进 NEW 的候选池**，最终 `owner=NEW|LEGACY` 仍由数仓按 `userId` 分桶决定（见改造计划）。
3. 对比效果时：用全量 CSV 的 `source` + `live_dpd` + `stage` + `product` 切片；**不要**只用 8/29 的桶名当今日渠道日。
4. 上线前再扫一遍结清：抽样后若还清，应从白名单拿掉（与 8/20→8/21 替补同一原则）。

### 建议验收对照

| 项 | 用本样本怎么验 |
|----|----------------|
| 只发 NEW | 白名单内被标 NEW 的案有 `caseEvent`；LEGACY 无消息 |
| 缺席对账 | 某日从 NEW 改为 LEGACY 后，活跃计划在 03:35 对账后取消 |
| userId 同桶 | 同 user 多案（本样本已一人一案，可另抽同 user 多案做专项） |
| DPD≤30 聚焦 | 名单内 `live_dpd` 均 ≤30；S4/D91 不在池内 |
